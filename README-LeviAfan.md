# LeviAfan Zapret GUI

Автор интерфейса: **LeviAfan**.
Основа: https://github.com/Flowseal/zapret-discord-youtube (версия 1.10.4).

## Запуск

1. Распакуйте весь архив в отдельную папку, например D:\Apps\LeviAfanZapret. Не переносите exe отдельно от bin, lists и utils.
2. Откройте LeviAfan-Zapret.exe и подтвердите UAC. Нужен Windows с .NET Framework 4.8 (обычно уже установлен в Windows 10/11).
3. Выберите стратегию и нажмите «Запустить». Окно winws скрыто; ошибки выводятся во вкладке инструментов.
4. Если ресурс недоступен, остановите обход и попробуйте другую стратегию. Результат зависит от провайдера.

## Возможности

- Все 22 штатные стратегии: запуск, остановка, перезапуск.
- Служба Windows: установка выбранной на главной вкладке стратегии для автозапуска, удаление и статус.
- Игровой фильтр: выключен / TCP+UDP / TCP / UDP, проверяемые диапазоны портов.
- IPSet: loaded / none / any; сохранение исходного списка для возврата в loaded.
- Пользовательские домены, доменные исключения и IP/CIDR-исключения. Редактирование остальных штатных списков тоже доступно.
- URL преобразуются в домены, поддерживаются международные домены (IDN), удаляются дубликаты. Перед сохранением создаётся .leviafan.bak.
- Выбор активных fake-пакетов через диалог файлов.
- Переключение штатной проверки обновлений, обновление IPSet и hosts, диагностика, очистка кеша Discord, тесты.
- Интерактивные штатные инструменты работают через текстовую панель GUI: вводите ответы в нижнее поле. Некоторые подтверждения требуют пустой строки и кнопки Enter. Тесты стратегий открывают штатное окно PowerShell.
- Трей: открыть, запустить, остановить, выйти; двойной щелчок открывает окно. Закрытие и сворачивание по умолчанию прячут окно.
- Настройки GUI хранятся в %LOCALAPPDATA%\LeviAfan\settings.txt.

После изменения фильтров, списков и fake-пакетов перезапустите ручную стратегию. Для установленной службы используйте повторную установку выбранной стратегии: параметры службы содержат порты на момент установки.

При полном выходе из GUI ручной запуск останавливается. Установленная служба работает независимо от интерфейса: её можно использовать для обхода с полностью закрытым GUI.

Кнопка «Остановить» останавливает службу zapret и процессы winws. Если есть winws, пользователь получает подтверждение, поскольку это затрагивает отдельно запущенные экземпляры.

## Ресурсы

Нативный Windows Forms, без Electron/WebView. Нет таймеров, фонового опроса статуса, анимаций и проверок обновлений GUI. В трее окно скрыто и ожидает события Windows. Журнал ограничен по размеру. Потребление движка winws зависит от трафика и стратегии; точные значения CPU/RAM на целевом ПК не измерялись.

## Проверка и сборка

Исходник: gui\Main.cs. Сборка: powershell -NoProfile -ExecutionPolicy Bypass -File gui\build.ps1
Проверки: powershell -NoProfile -ExecutionPolicy Bypass -File gui\verify.ps1

Проверены компиляция, создание и отрисовка главного окна, нормализация доменов, IDN, дубликаты, отклонение неверных доменов/CIDR и разбор команд всех стратегий. Сетевой обход, установка службы, изменение hosts, диагностика с исправлениями и внешние обновления в этой среде не запускались.
